# Prioritize the command research track

The next research phase prioritizes whether the Quest can become a reliable ExpressLRS pilot input source for ExpressLRS micro FPV drones, using the Air65 as the current Validation Aircraft. Video Integration Research continues as a separate branch, but the Command Research Track is the main project risk because Control-First Validation depends on proving the Command Path and Trustworthy Control Feel before the broader cockpit is complete.
