# Design for simulator-to-real continuity

The Quest-Native Flight Station should preserve Simulator-to-Real Continuity wherever practical: Quest Control Schemes, calibration concepts, Command Visualization, and Flight Session language should transfer between simulator and real-drone sessions. Command and video mechanisms differ by Session Environment, but the simulator should still be a proving ground for Trustworthy Control Feel instead of a separate experience that must be relearned before real flight.
