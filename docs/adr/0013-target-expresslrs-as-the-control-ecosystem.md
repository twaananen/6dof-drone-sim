# Target ExpressLRS as the control ecosystem

The Quest-Native Flight Station targets ExpressLRS micro FPV drones rather than trying to be radio-agnostic. This focuses the Command Research Track on the real control ecosystem in front of us, with the Air65 as the current Validation Aircraft, while leaving other radio systems outside the current product definition. If receiver-native firmware repurposes onboard ELRS receiver hardware without normal ExpressLRS RF control, that product-boundary tension must be reviewed explicitly rather than hidden under the ExpressLRS label.
